## 一、文档概述

### 1.1 项目定位

从零构建的通用型微服务架构，提供生产级基础设施、标准化开发规范和完整CI/CD交付流程。

### 1.2 核心目标

- 构建可复用的基础框架Starter集合
- 实现服务注册发现、配置管理、网关路由、限流熔断、认证授权等核心能力
- 建立完整的容器化部署和CI/CD流水线
- 深度掌握SPI、Spring Boot自动配置等底层机制

### 1.3 技术原则

| 原则 | 说明 |
|------|------|
| 约定优于配置 | 提供合理的默认值，降低使用门槛 |
| 开闭原则 | 通过SPI和条件注解支持扩展，核心逻辑封闭 |
| 可观测性优先 | 所有组件必须暴露日志、指标、链路信息 |
| 云原生友好 | 支持容器化部署和K8s编排 |

## 四、核心组件设计

### 4.1 believe-common-core

**职责**：提供最基础的工具能力和公共契约。

**核心能力**：
- `Result<T>`、`PageResult<T>` 统一返回格式：`{code, message, data, timestamp}`
- `AuthContext`（ThreadLocal）和 `RequestContext`（ThreadLocal）上下文持有
- 异常体系：`BelieveException`、`BizException`
- 工具类：`JsonUtil`（Jackson 3）、`DateUtil`、`IdUtil`
- 错误码规范：1xxx参数错误，2xxx业务错误，3xxx系统错误，4xxx权限错误，5xxx服务调用错误

### 4.2 believe-common-redis

**职责**：Redis操作封装。

**暴露Bean**：
- `RedisTemplate<String, Object>`（Jackson 3序列化）
- `RedisDistributedLock`（基于SET NX EX + Lua）
- `CacheManager`（Spring Cache集成，默认TTL 1小时）

### 4.3 believe-common-data

**职责**：数据持久化增强，四种数据源模式互斥激活。

| 模式 | 激活条件 | 说明 |
|------|----------|------|
| 单数据源 | 默认 | 开发环境 |
| 读写分离 | `believe.data.read-write-split.enabled=true` | 主从架构 |
| 多数据源 | `believe.data.multi-datasource.enabled=true` | 多库独立 |
| 分库分表 | `believe.data.sharding.enabled=true` | 水平拆分 |

**其他能力**：
- `@DataSource` 注解 + AOP动态切换数据源
- MyBatis-Plus分页插件、乐观锁插件
- 自动填充：`createTime`、`updateTime`、`createBy`、`updateBy`、逻辑删除
- `BaseEntity` 抽象基类
- `CustomSqlInjector` 批量插入支持

### 4.4 believe-common-spi

**职责**：SPI扩展点接口定义。

| 扩展接口 | 方法 | 说明 |
|----------|------|------|
| `NotifyChannel` | `send` / `sendAsync` | 通知渠道 |
| `IdGenerator` | `nextId` / `nextIdStr` | 分布式ID生成 |
| `DataSerializer` | `serialize` / `deserialize` | 数据序列化 |

**加载机制**：Java原生 `ServiceLoader` + Spring `@ConditionalOnMissingBean`。

### 4.5 believe-common-spi-extension

**职责**：为上述扩展点提供生产级默认实现。

#### 通知渠道

| 实现 | 激活条件 | 说明 |
|------|----------|------|
| `SmsNotifyChannel` | `believe.spi.notify.sms.api-url` | 短信网关 |
| `EmailNotifyChannel` | `JavaMailSender` + `believe.spi.notify.email.from` | 邮件发送 |
| `DingTalkNotifyChannel` | `believe.spi.notify.dingtalk.webhook-url` | 钉钉机器人 |

#### 分布式ID生成器

| 实现 | 算法 | 激活条件 |
|------|------|----------|
| `SnowflakeIdGenerator` | 雪花算法 | 默认启用 |
| `LeafSegmentIdGenerator` | 美团Leaf号段 | `DataSource` + `believe.spi.id.leaf.biz-tag` |

#### 序列化器

| 实现 | 格式 | 激活条件 |
|------|------|----------|
| `JsonDataSerializer` | JSON（Jackson 3） | 默认启用 |
| `ProtobufDataSerializer` | Protobuf | `MessageLite` 在classpath |

**覆盖机制**：所有Bean均通过 `@ConditionalOnMissingBean` 注册，业务方可自定义替换。

**配置前缀**：`believe.spi`

| 配置项 | 示例 |
|--------|------|
| `notify.sms.api-url` | `https://sms.example.com/send` |
| `notify.email.from` | `noreply@believe.com` |
| `notify.dingtalk.webhook-url` | `https://oapi.dingtalk.com/robot/send?access_token=xxx` |
| `id.snowflake.worker-id` | `1` |
| `id.snowflake.datacenter-id` | `1` |
| `id.leaf.biz-tag` | `order_id` |
| `id.leaf.step` | `2000` |

### 4.6 believe-common-exception

**职责**：全局异常统一处理，错误码→HTTP状态码映射。

- `BelieveException` → 按错误码分类（1xxx/2xxx→400，3xxx→500，4xxx→401/403，5xxx→502）
- 参数校验异常 → 400
- 404 → 404
- 兜底 → 500

### 4.7 believe-common-log

**职责**：日志链路追踪与AOP方法日志。

- `@Log` 注解：记录入参、耗时、异常
- `TraceIdFilter`：提取/生成TraceId，写入MDC和RequestContext

### 4.8 believe-common-feign

**职责**：Feign远程调用增强。

- `FeignRequestInterceptor`：自动注入 `X-Trace-Id`、`X-User-Id`、`X-Username`、`Authorization`

### 4.9 believe-common-swagger

**职责**：Knife4j API文档自动配置。

### 4.10 believe-common-mq

**职责**：消息队列统一封装，支持RocketMQ/RabbitMQ/Kafka三选一，通过 `believe.mq.type` 切换。

### 4.11 believe-common-security

**职责**：`AesUtil`（AES 256位 GCM加解密）。

### 4.12 believe-gateway

**职责**：统一流量入口。

**过滤器链**（Order顺序）：
- -2 `AuthGlobalFilter`：JWT解析
- -1 `TraceIdGlobalFilter`：TraceId生成
- 0 `RateLimitGlobalFilter`：Sentinel限流
- 1 `GrayReleaseGlobalFilter`：灰度路由
- 5 `RequestLogGlobalFilter`：请求日志

**路由规范**：`/api/{service-name}/**` → 对应微服务；白名单 `/auth/**`、`/actuator/**` 绕过认证。

### 4.13 believe-auth

**职责**：认证授权中心（RBAC 5表模型），JWT（RS256）颁发与校验。

### 4.14 believe-job

**职责**：xxl-job执行器封装，提供 `@BelieveXxlJob` 增强。

## 十、关键版本说明

### v3.1 相对于 v2.9 的核心变化

- 新增 `believe-common-spi-extension` 模块，提供短信/邮件/钉钉、雪花/Leaf号段、JSON/Protobuf的默认实现
- 所有默认实现均支持 `@ConditionalOnMissingBean` 覆盖
- 统一配置前缀 `believe.spi`

### Spring Boot 4.0 重要提醒

1. Servlet API 升级为 `jakarta.servlet.*`（Servlet 6.1）
2. Jackson 3 核心包名变更为 `tools.jackson.*`，使用 `JsonMapper.builder()`
3. 无独立 `spring-boot-starter-aop`，需直接引入 `spring-aop` 和 `aspectjweaver`
4. 日期配置使用 `DateTimeFeature.WRITE_DATES_AS_TIMESTAMPS`
